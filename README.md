A tiny stdlib-only Python program that writes one line inventing the most useless superpower imaginable — talking to goldfish who only ever want to talk about being goldfish — to `entry.txt`, for make.fun's "Worst Superpower" bounty.

## Run it

```sh
python3 main.py
```

This writes the one-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default).
